# Исследование рынка стартапов (EDA)

Исследовательский анализ данных о стартапах, сделках по их покупке и раундах финансирования. Финальный проект Python-модуля курса Яндекс Практикума «Аналитик данных расширенный».

**Стек:** Python, pandas, numpy, matplotlib, seaborn, missingno, matplotlib-venn, Jupyter

---

## Задача

Инвестиционная компания выходит на рынок покупки и перепродажи стартапов. Нужно исследовать исторические данные и понять, что влияет на успешность и стоимость сделки: отрасль, финансирование, регион, возраст компании. Данные неполные, поэтому отдельная цель — честно оценить их качество и искажения.

## Данные

Семь связанных таблиц: сделки по покупке компаний, компании и раунды финансирования (217 тыс. строк), сотрудники и их образование, фонды, раунды инвестирования.

## Что сделано

- **Предобработка:** приведение дат к `datetime`, поиск скрытых пропусков в виде строки `'nan'`, анализ доли пропусков по каждому столбцу, визуализация структуры пропусков через `missingno`.
- **Восстановление структуры:** таблица `company_and_rounds` оказалась склеена из двух сущностей (компании и раунды), разделена обратно с сохранением связности.
- **Выбор ключа объединения:** через множества и диаграммы Венна показано, что для объединения подходит `company_id`, а `network_username` нет.
- **Работа со скошенными денежными данными:** медиана вместо среднего, логарифмирование (`np.log1p`), лог-шкала, boxplot; выбросы по IQR и по процентилям.
- **Анализ:** динамика раундов финансирования по годам, цены покупки и их разброс по категориям стартапов, число раундов по статусу компании, класс аномальных сделок за 0–1 доллар при крупном финансировании.

## Ключевые выводы

- Рынок венчура стал массовым: к 2013 году рекорд по числу раундов при снижении медианного чека на раунд.
- Цена и разброс цен сильно зависят от категории: технологичные и биотех-направления дороже и рискованнее.
- Есть отдельный класс аномалий — сделки за символическую цену (0–1 доллар) у компаний с крупным финансированием.
- На цену сделки влияет не только объём финансирования, но и отрасль, регион и возраст компании.
